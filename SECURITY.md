# Security Policy

## Supported versions

jobq is in early development. Security fixes are applied to the default branch; older revisions are not maintained.

## Reporting a vulnerability

Do not report vulnerabilities through public issues or pull requests.

If GitHub private vulnerability reporting is enabled, use:

https://github.com/akash1047/jobq/security/advisories/new

If it is unavailable, contact the maintainer through a private contact method listed on their GitHub profile to arrange a reporting channel. Do not include vulnerability details in public messages.

Include affected revisions, reproduction steps, potential impact, and a suggested fix if available. Remove credentials and personal information.

Response and remediation times are not guaranteed during early development.

## Deployment

Do not expose the API to untrusted networks without authentication and authorization. Keep database credentials outside version control and restrict database access.
